# 功能特性

Conclave 是一个多智能体结构化决策系统。本文按模块介绍它能做什么。

## 决策引擎

**六阶段会议管线**。一次决策被组织为一场正式会议：澄清（clarify）→ 队内讨论（intra_team）→ 跨队辩论（cross_team）→ 证据校验（evidence_check）→ 仲裁裁决（arbitrate）→ 产出交付（produce）。每个阶段有质量门禁，遇到异常会自动回退或兜底，而非静默失败。

**7 种内置角色**。产品架构师、工程师、安全专家、UX 设计师、数据工程师、市场专家、主持人。每种角色有独立的人格、风险偏好与证据偏好，在辩论中从不同立场审视同一个议题。

**动态借调**。主持人会根据议题复杂度申请补充专家角色，如议题涉及财务时临时借调财务专家。

**证据诚实**。每一条论点都会被标注来源类型：文档、网页、常识、假设。若论点找不到证据支撑，系统会诚实降级置信度，而不是编造引用。这是 Conclave 与普通「单次生成」最本质的区别。

**五层确定性**。参数约束、结论锁定、漂移检查、全链路追踪、自动降级兜底，共同保证结论可复现、推理可追溯。

## 执行与交付

**Docker 沙箱隔离**。需要执行代码时，在独立的兄弟容器中运行，与宿主环境安全隔离。

**多主机分布式调度**。可注册远程 Docker 主机（SSH / TCP+TLS / Unix Socket），内置 5 种调度策略：least_loaded、local_first、tag_match、manual、round_robin。

**可部署服务交付**。会议结论可以直接生成一个可运行的 FastAPI 后端 + React 前端服务，并自动部署到沙箱运行起来。

**自动代码修复**。生成的代码执行失败时，系统会自动分析错误并尝试修复（RefineLoop，默认最多 5 轮）。

**Web 搜索**。Agent 可以通过 Playwright 浏览器主动检索互联网资料来支撑自己的论点。

## 企业级能力

- **多租户隔离**：租户级数据隔离、配置覆盖、系统租户上下文
- **认证安全**：JWT + HttpOnly Cookie + CSRF 防护 + Token 刷新
- **RBAC 权限**：基于角色的访问控制，插件化实现
- **审计日志**：关键操作全部写入 PostgreSQL
- **成本追踪**：Token 与费用按会议、模型、角色实时统计

## 可观测性

- **实时日志面板**：可折叠面板流式展示所有节点执行日志，按级别着色
- **联通视图**：服务依赖关系、网络隔离层级、实时健康状态
- **Token 与成本监控**：LLM 调用费用与用量实时统计
- **LLM 调用追踪**：全链路 CallTrace，保证可复现

## RAG 检索增强

- **bge-m3** 多语言 Embedding + **bge-reranker-v2-m3** 重排序
- **HyDE** 假设文档嵌入，提升模糊查询召回率
- **Multi-Query 扩展**：自动生成多个查询变体，扩大召回覆盖面
- **Qdrant 向量库**（生产）与内存向量库（开发模式）
- **文档上传**：为会议关联参考文档，Agent 可基于文档作答

## 沙箱架构

后端以 root 启动，自动配置 Docker socket 权限并预拉取沙箱镜像，然后降权运行服务。运行时通过 Docker API 创建临时兄弟容器执行用户代码。工作区通过命名卷在后端与沙箱容器间共享。
